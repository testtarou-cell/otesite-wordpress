# O・TE Dance School WordPress版

元サイト https://github.com/testtarou-cell/otesite の6ページを、元のCSS・JavaScript・画像を使用してWordPress化しました。テーマと管理機能プラグインの2つをインストールします。有料プラグイン・サーバー上のNode.jsは不要です。

## InfinityFreeへの導入

1. 念のため既存WordPressのファイル・データベースをバックアップします。
2. 管理画面「プラグイン → 新規プラグインを追加 → プラグインのアップロード」で `ote-content.zip` をアップロードし、有効化します。
3. 「外観 → テーマ → 新しいテーマを追加 → テーマのアップロード」で `ote-dance.zip` をアップロードし、有効化します。
4. 「設定 → 表示設定」でホームページを「最新の投稿」に設定します。本テーマは専用の6ページを表示するため、この設定でも投稿一覧にはなりません。
5. テスト環境では同じ画面で「検索エンジンがサイトをインデックスしないようにする」を選びます。閲覧制限にはなりません。
6. 「O・TE コンテンツ」を開き、初期内容を確認して「変更を保存」を押します。
7. サイトを開き、下記のチェックを実施します。画像変更後も古い画像が見える場合はブラウザーを再読み込みします。

サーバーのZIPアップロード制限に当たる場合は、それぞれ展開して `wp-content/themes/ote-dance/` と `wp-content/plugins/ote-content/` にFTPまたはファイルマネージャーで配置し、管理画面で有効化してください。PHP 8.0以上、WordPress 6.5以上を想定しています。

## 編集方法

管理者権限で「O・TE コンテンツ」を開きます。各見出しをクリックして編集欄を開きます。すべての変更はページ下部の「変更を保存」で確定します。

- **トップのお知らせ**：分類ラベル、本文、リンク、公開状態を編集。追加・削除・上下移動が可能です。リンク空欄ならスケジュールに移動します。
- **あなたに合う、ダンスがある。**：キッズ・ジュニア／一般／キッズ親子の3枚を個別に差し替え。「画像を選択」でメディアライブラリから選びます。「初期画像に戻す」で元の画像に戻せます。
- **FAQ**：質問・回答を追加・編集・削除・上下移動。回答の改行に対応します。
- **スケジュール**：対象年・月、月間表画像、画像の説明、日付別の項目を編集。各日付の中に時間・名称・補足のレッスンを追加できます。休講などはレッスンを0件にして補足欄へ入力します。日付は保存時に昇順になります。
- **料金**：入会金・登録料／一般／ジュニア／親子／その他ごとに項目を追加・編集・削除・上下移動。金額は数値なら桁区切り、「要相談」などの文字でも登録できます。各区分の固定見出し・説明文はテーマ側です。

スケジュール画像と日付別一覧は独立したデータです。両方更新してください。画像の自動読み取りはありません。元資料の年が不明のため、初期状態の年は空欄です。曜日を推測で補完せず元資料に従ってください。年を入れた場合は実在する日付か検証しますが、曜日の自動計算はしません。

全件削除したリストは空のまま保存します。テーマやプラグインを再度有効化しても既存データを上書きしません。テーマを切り替えてもDBの `ote_content` オプションに内容が残ります。異なるテーマでの表示には、そのテーマ側の対応が必要です。データのバックアップにはWordPressデータベースのバックアップを使ってください。

## URL

ホームはWordPressのホームURLです。ほかのページは `/?ote_page=about`、`join`、`schedule`、`fees`、`privacy` を使用します。サブディレクトリへの設置にも対応します。パーマリンクやサーバーのrewrite設定を追加する必要はありません。

このテーマは6ページ専用です。通常のブログ投稿一覧や任意の固定ページを表示する汎用テーマではありません。ヘッダー・本文の固定文・LINE・住所など、指定された編集範囲以外は元サイトの内容を保持しています。

## テスト手順

1. PC・スマートフォンで6ページ、メニュー、LINE・Instagram・地図リンク、写真拡大を確認。
2. お知らせを追加し保存 → 編集して保存 → 非公開 → 削除して保存。
3. 3枚のクラス写真をそれぞれ差し替えて確認。月間表画像も変更して確認。
4. FAQを追加・編集・上下移動・削除して確認。
5. 日付を追加し、その日のレッスンを複数追加。時間・補足を変更し、レッスンと日付を削除。
6. 全料金区分で追加・金額変更・上下移動・削除を確認。
7. 日付重複や不正な年月の保存でエラーが表示され、元データが維持されることを確認。
8. 各リストを空にして保存しても公開ページにエラーが出ないことを確認。
9. 再ログイン・テーマ切り替え後にも保存内容が残ることを確認。

## 実施済みのローカル確認

- PHP 8.3.35で全PHPファイルの構文チェック。
- 6ページの初期DOM構造・文章が元HTMLと一致することを確認。
- トップの全ページ画像比較：1440px・390pxともピクセル差分なし（ログアウト相当・初期データ）。
- 6ページ×PC/スマートフォンでブラウザー実行・元サイトと同じページ幅を確認。
- 編集／空リスト時のレンダリング、変更画像・追加料金・追加予定・HTML文字のエスケープを確認。
- 編集UIの追加・編集・削除・並べ替え・日付内のレッスン追加・保存用データの生成をブラウザー確認。
- URLサニタイズ、重複日付、不正な日付、空リストの保存処理を確認。

ローカル確認はWordPress関数を代替した独立レンダラーとブラウザーで実施しました。実際のWordPress DB・メディアライブラリ・options.php保存、InfinityFree上の導入、ログイン時の管理バーは未検証です。導入後に上記の実機チェックを行ってください。

## 配布ZIPの再作成

`python scripts/package.py` で `releases/ote-dance.zip` と `releases/ote-content.zip` を作成できます。WordPressへはリポジトリ全体のZIPではなく、この2つをそれぞれアップロードします。

画像の出典は `ASSETS.md` を参照してください。元サイトの写真・料金・予定は確認用の内容を引き継いでいます。
